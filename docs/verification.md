# Проверки и ограничения Lunavect

Обновлено 2026-09-12. Локальная сборка и тесты не заменяют испытание установщика на другом Mac или результат GitHub Actions.

## Исправления после аудита

| Область | Изменение и проверка |
|---|---|
| Сохранность настроек | Повреждённый snapshot сохраняется отдельным файлом до новой записи. Валидные настройки и даты подписок восстанавливаются отдельно от повреждённых квот. Ошибки доступа блокируют запись. Проверены исходные байты и права резервного файла. |
| Статистика | Повреждённая история и детализация сохраняются отдельно; новый сбор продолжает работу. Старые отчёты без новых счётчиков читаются. Предупреждение о восстановлении не отключает график. |
| Подключения после переноса | Проверяется существование исполняемого файла и точная команда каждого обработчика. При запуске исправляются пути уже настроенных подключений. Тесты сохраняют сторонние обработчики и символические ссылки на конфиги. |
| Отключение Claude | Восстанавливается сохранённый statusLine, включая дополнительные поля. Если пользователь заменил его самостоятельно, новый вариант сохраняется. Без резервной копии операция сообщает об ошибке. Проверены отключение и повторное подключение на изолированных файлах. |
| Фоновые лимиты | `/usage` работает с `CLAUDE_CODE_SKIP_PROMPT_HISTORY=1`. Живой запрос через установленный Claude Code получил квоты; количество и список принадлежащих зонду записей истории/транскриптов до и после совпали. Свежий локальный снимок позволяет пропустить очередной фоновый процесс; ручное обновление запрашивает новые данные. |
| Старые служебные события | Под общим lock очищаются собственные записи старше суток и неиспользуемые старые lock-файлы. Недавно записанные события, живые записи и чужие файлы сохраняются. Истории Claude/Codex не затрагиваются. |
| Процессы CLI | Чтение stdout имеет собственный срок ожидания, включая случай, когда дочерний процесс удерживает канал после завершения родителя. Ограничение действует и для каталога сессий, и для квот Codex. Клиент теперь определяется через libproc по родительским PID и путям исполняемых файлов, без запуска `ps`. |
| WidgetKit | Эксперимент выключен по умолчанию (включая старые настройки без этого поля), сохранённый явный выбор сохраняется. Он проверяет типы методов до подмены, при несовместимости использует стандартное поведение. Проверены включение/выключение/включение, три цикла архивирования и отсутствие вмешательства в чужой descriptor. Тест несовместимого ABI включён в check.sh. |
| Читаемость виджета | У лимитов появилась такая же самостоятельная подложка, как у статистики. Убрано дополнительное затемнение контейнера. Нативно осмотрены белый и чёрный фон при максимальной прозрачности. Это не проверка живого рабочего стола после сна. |
| Переводы | Сообщения восстановления и отключения, а также пропущенная кнопка открытия клиента переведены на английский, немецкий, испанский, французский и упрощённый китайский. Каталог проверен на полноту языков и сохранность подстановок. |
| Публикация | MIT выбрана владельцем. LICENSE и NOTICE добавлены; сведения сторонних ресурсов сохранены. Эскизы, веб-макеты и внутренние журналы остаются локально и исключены из Git. Первый локальный коммит подготовлен; публикация отмечается отдельно. |

## Предыдущий проход — сборка 101

- `./scripts/check.sh`: 262 теста, 233 прошли, 29 opt-in проверок пропущены; Release приложения и расширения собран без подписи. Проверки descriptor также прошли.
- Изменение чтения квот Codex дополнительно проверено соответствующими тестами: 52 теста, 51 прошёл, один живой тест пропущен; затем выполнен общий прогон выше.
- Отдельно прошёл живой `/usage` Claude без запроса модели; записи истории и транскриптов зонда не добавились.
- Отдельно прошёл нативный рендер лимитов на светлом и тёмном фоне.
- Установлена подписанная сборка 101. В живой панели проверены снятие рамки кликом по пустому месту и Escape, открытие меню через «…». После установки общий снимок получил свежие квоты обоих сервисов без ошибок.
- После этих проверок канал инструмента UI закрылся; повторный осмотр настроек недоступен. Процесс приложения продолжает работать. Работа самого системного виджета после сна в этом проходе не подтверждена.

## Повторный аудит — сборка 102

- По умолчанию `build.sh`/`install.sh` используют Release; установленная копия не содержит debug dylib. Явный `WEEKLEFT_BUILD_CONFIGURATION=Debug` остаётся для отладки.
- Закрытая панель отключает свою иерархию с TimelineView, сохраняя фильтры сессий. Нативный тест проверил реальные тики, их прекращение при скрытии и возобновление при открытии. Отдельный тест проверяет отсутствие повторных публикаций одинаковых строк и публикацию при устаревании статуса; наблюдения статистики продолжаются.
- Добавлен файловый наблюдатель событий и интервалы резервного опроса 1/2/5 секунд (открытая панель/активные сессии/бездействие). Каталог и названия — 15/45 секунд. Период каталога меньше срока достоверности 60 секунд. Ресурсы логотипов читаются один раз.
- Встроен отдельный `LunavectHook`; проверены отсутствие AppKit/SwiftUI/Sparkle в зависимостях, ответы входов Claude/Codex и подпись установленного пакета. На этом Mac все собственные hook-команды и Claude statusLine автоматически переведены на помощник. Свежие квоты обоих провайдеров получены после установки.
- 20 чередующихся запусков каждого бинаря Release после 3 прогревов: медиана помощника 5,22 мс, GUI-входа 8,10 мс; p95 5,41/8,42 мс. Вход `{}` без ID не создаёт событий и не пишет квоты. Это измерение запуска, а не полного события с диском и пользовательским HUD. 110 мс из внешнего аудита в иных условиях не является сопоставимой базой.
- `./scripts/check.sh`: 267 тестов, 238 прошли, 29 opt-in проверок пропущены; unsigned Release с WidgetKit и новым помощником собран. Подпись и App Group установленной сборки проверены отдельно. Проверка встроенного помощника добавлена в сборку/установку/CI и отдельно выполнена на подписанном артефакте.
- Дополнительно выполнен нативный рендер стандартного и экспериментального фона на белой/чёрной поверхности (четыре изображения), результат осмотрен. Он не доказывает поведение WidgetKit на рабочем столе после сна.
- Профиль установленного процесса: build 101 Debug — 9,65% CPU за 20,3 с; build 102 Release — 3,79% за 25,3 с, с анимацией значка и работающей сессией. Видимость окон во время замеров надёжно не подтверждена; это не чистый замер простоя и не изолированная оценка оптимизации. В новом пятисекундном sample не обнаружены стеки SessionsView/TimelineView, присутствовавшие в старом; остановку таймера независимо проверяет нативный тест.
- Установленная панель открылась и вернула дерево элементов, но дальнейшие действия CUA снова завершились ошибкой native pipe. Повторный цикл закрытия/открытия и сохранность фильтра в установленной панели пока не подтверждены. Нативные тесты выше не выданы за ручную проверку.

## Что остаётся перед публичным выпуском

- Подпись для распространения, notarization, установщик, согласованный GitHub-репозиторий и реальный первый выпуск. Локальная подпись не является Developer ID-проверкой установщика.
- Установка из чистой копии и первоначальное подключение на другом Mac, перенос из DMG, обновление со старой версии и отключение без прежних настроек автора.
- Проверка заявленных macOS/архитектур, реального системного виджета после сна и обновления системы. Private API остаётся экспериментом даже с проверками ABI; гарантии совместимости нет.
- Сквозное скачивание и установка подписанного обновления через две опубликованные версии GitHub/Sparkle.
- Реальный длительный цикл нескольких сессий обоих клиентов, включая ожидание разрешения и отсутствие событий. Тесты отдельных переходов не заменяют эту проверку.
- Финальная сверка состава релизного коммита при последующих изменениях. Исключение больших эскизов не является полным аудитом содержимого.

Маскоты сохранены по прямому решению владельца. MIT относится к нашему коду и не предоставляет дополнительных прав на сторонние изображения. Сведения о происхождении и текущем статусе разрешений — в [NOTICE](../NOTICE) и [mascot-permissions.md](mascot-permissions.md).

## Следующие улучшения

Сквозная проверка сна/пробуждения, длительной работы нескольких клиентов и режима закрытой крышки остаётся отдельной задачей. Режим закрытой крышки и недокументированный фон не следует представлять как проверенные на любом Mac.

Документированный режим Claude: [environment variables](https://code.claude.com/docs/en/env-vars). Авторизация выполняется в официальном клиенте; Lunavect не извлекает и не копирует его учётные данные.
